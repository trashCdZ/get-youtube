Готово к просмотру

Мини-инструкция

Запуск за 4 шага

Подробная инструкция всегда доступна в репозитории. Здесь — короткий маршрут.

  1. 1

    Перейдите в GitHub-репозиторий

    Откройте официальный репозиторий проекта — только он гарантирует актуальную и безопасную версию.

    flowseal/zapret-discord-youtube →
  2. 2

    Скачайте последнюю версию

    В разделе Releases выберите свежий релиз и скачайте архив. Распакуйте его в удобную папку.

    Releases → последний .zip / .rar архив

  3. 3

    Запустите файлы по инструкции

    Запустите необходимые файлы из архива согласно README проекта. При запросе — подтвердите права администратора.

    📍 Для Крыма: желательно запускать general (ALT11).bat — этот режим лучше работает с местными провайдерами.

    ⚠ Если антивирус ругается — это ложное срабатывание на сетевую утилиту. Проверяйте файлы только из официального репозитория.

  4. ✓

    Проверьте работу YouTube

    Откройте YouTube и включите видео в 1080p или 4K. Если всё грузится быстро — готово. Не помогло? В репозитории есть альтернативные режимы запуска.
