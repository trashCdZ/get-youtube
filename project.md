# PROMPT ДЛЯ MUSE SPARK

Создай современный одностраничный лендинг в стиле **Dark Tech / Cyberpunk** для проекта **Zapret Discord + YouTube**.

## Цель сайта
Сайт предназначен для пользователей Windows и объясняет, как использовать проект Zapret для восстановления доступа и стабильной работы YouTube. Главная цель — дать краткую инструкцию и перенаправить пользователя на GitHub-репозиторий для скачивания.

Использовать официальный репозиторий:
https://github.com/flowseal/zapret-discord-youtube

---

Стиль:

Создать красивый пошаговый блок:
